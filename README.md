# 모도

친구들이랑 안 되는 날만 칠하면, 다 같이 되는 날을 찾아 주는 캘린더.

- 사이트: https://kim-jae-ung.github.io/modo/
- 데이터: Supabase `modo` 프로젝트의 `modo_docs` 표 (일정마다 나뉨), 초대 코드는 `modo_codes` 표

## 쓰는 법

- 첫 화면: **내 일정**(이 기기에서 들어간 일정 목록), **일정 찾기**(일정 이름·큰 일정 이름으로), **초대 코드로 들어가기**, **새 일정 만들기**
- 새 일정을 만들 때 **총 인원**을 정해요. 나중에 일정 안 멤버 칸에서 바꿀 수 있어요.
- 각자 안 되는 날을 칠하고 **다 칠했어요**를 눌러요. 총 인원이 다 누르면 그때 **다 같이 가능한 날**이 떠요.
- 일정 안 **친구 초대**: 8자리 초대 코드(예: ABCD-EFGH)와 링크를 일정 이름과 같이 보내요.

## 구조

- `index.html`: 화면과 동작 전부 (빌드 과정 없음)
- `assets/`: 로고, 앱 아이콘, 링크 미리보기 이미지
- `supabase/schema.sql`: 표, 접근 규칙(RLS), `modo_pull` / `modo_put` / `modo_patch` / `modo_code` / `modo_join` 함수

## 알아 둘 것

- 초대 코드나 링크가 있는 사람은 누구나 그 일정을 보고 고칠 수 있어요. 코드를 모르면 아무것도 못 읽어요.
- 내 일정 목록과 이름 선택은 기기마다 저장돼요. 다른 폰에서는 초대 코드로 한 번 들어가면 돼요.
- 링크 미리보기 카드는 정적 사이트라 모든 링크가 똑같이 보여요. 대신 초대 메시지에 일정 이름과 코드가 들어가요.
- Supabase 무료 프로젝트는 7일 동안 아무 요청이 없으면 일시정지돼요. 대시보드에서 Restore 하면 데이터 그대로 다시 켜져요.
