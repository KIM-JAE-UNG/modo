# 모도

친구들이랑 안 되는 날만 칠하면, 다 같이 되는 날을 찾아 주는 캘린더.

- 사이트: https://kim-jae-ung.github.io/modo/
- 데이터: Supabase `modo` 프로젝트의 `modo_docs` 표 (초대 링크의 코드별로 나뉨)

## 구조

- `index.html`: 화면과 동작 전부 (빌드 과정 없음)
- `assets/`: 로고, 앱 아이콘, 링크 미리보기 이미지
- `supabase/schema.sql`: 표, 접근 규칙(RLS), `modo_pull` / `modo_put` / `modo_patch` 함수

## 알아 둘 것

- 초대 링크(`#` 뒤 코드)가 있는 사람은 누구나 그 캘린더를 보고 고칠 수 있어요. 코드를 모르면 아무것도 못 읽어요.
- 이름 선택은 기기마다 저장돼요. 다른 폰에서 열면 이름을 한 번 더 고르면 돼요.
- Supabase 무료 프로젝트는 7일 동안 아무 요청이 없으면 일시정지돼요. 대시보드에서 Restore 하면 데이터 그대로 다시 켜져요.
